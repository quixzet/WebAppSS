# Backend — Расписание СИЭУиП

Бэкенд для приложения расписания занятий студентов СИЭУиП (Самарский институт экономики и управления).

## 📦 Технологии

- **FastAPI** — веб-фреймворк
- **BeautifulSoup4** — парсинг HTML
- **pdfplumber** — парсинг PDF
- **APScheduler** — планировщик задач
- **SQLite** — база данных
- **aiohttp** — асинхронные HTTP запросы

## 🏗 Структура

```
backend/
├── main.py              # FastAPI приложение, API endpoints
├── database.py          # Работа с SQLite базой данных
├── scheduler.py         # APScheduler для автообновления
├── parsers/
│   ├── __init__.py
│   ├── html_parser.py   # Парсинг HTML страницы sielom.ru/schedule
│   └── pdf_parser.py    # Парсинг PDF файлов с расписанием
├── requirements.txt     # Python зависимости
└── README.md           # Этот файл
```

## 🚀 Установка и запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера (порт 8000)
python main.py

# Или через uvicorn
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## 📊 Источник данных

**URL:** https://sielom.ru/schedule

Процесс парсинга:
1. Загрузка HTML страницы расписания
2. Извлечение ссылок на PDF файлы (по корпусам и специальностям)
3. Парсинг каждого PDF файла с извлечением занятий
4. Сохранение в базу данных с обнаружением изменений

## ⏰ Автоматическое обновление

Планировщик (APScheduler) выполняет:
- **Ежедневный парсинг** — каждый день в 03:00 по Москве
- **Проверка актуальности** — каждые 6 часов
- **Очистка данных** — каждое воскресенье в 04:00

При старте приложения автоматически проверяется необходимость обновления:
- Если данных нет — запускается парсинг
- Если данные старше 24 часов — запускается парсинг
- Если последнее обновление было неудачным — запускается парсинг

## 🔄 Retry механизм

Все HTTP запросы имеют встроенный retry механизм:
- Максимум 3 попытки при ошибке
- Задержка 5 секунд между попытками
- User-Agent заголовок для имитации браузера
- Обработка кодировки UTF-8/cp1251

## 📱 Telegram интеграция

Подготовлена инфраструктура для отправки уведомлений через Telegram Bot API:
- Таблица подписок в БД
- Обнаружение изменений в расписании
- Форматирование сообщений об изменениях
- Функция отправки через Bot API (нужен токен)

Для включения уведомлений установите токен бота:
```python
BOT_TOKEN = "your_bot_token_here"
```

## 🗄 База данных

SQLite база `schedule.db` с таблицами:
- `groups` — список групп
- `schedules` — расписание занятий
- `last_update` — время последнего обновления
- `subscriptions` — подписки на уведомления
- `changes` — журнал изменений
- `pdf_sources` — источники PDF файлов

## 📝 Логирование

Все операции логируются с уровнями:
- `INFO` — успешные операции
- `WARNING` — предупреждения (повторные попытки)
- `ERROR` — ошибки парсинга/обновления
- `DEBUG` — детальная информация (при необходимости)
